# Industrial Data Platform for a 100-Machine Smart Factory

## 1. Introduction

Modern manufacturing industries generate large volumes of data through industrial machines, sensors, production systems, and equipment monitoring. Efficiently managing this data is essential for improving productivity, reducing operational costs, and enabling predictive maintenance.

This project, titled **Industrial Data Platform**, focuses on designing and implementing a scalable cloud and data infrastructure for a smart factory operating 100 CNC machines across three manufacturing plants.

The platform integrates data engineering, cloud architecture, database management, machine learning, and data visualization to support industrial monitoring and analytics.

## 2. Problem Statement

A manufacturing company operating 100 CNC machines across three plants requires a reliable system to collect, process, store, and analyze machine-generated data.

The main challenges include:

- Handling large volumes of sensor and production data.
- Designing an efficient edge-to-cloud data pipeline.
- Selecting an appropriate cloud provider.
- Storing and querying industrial data efficiently.
- Monitoring machine performance and predicting potential failures.
- Visualizing operational insights through dashboards.

The project addresses these challenges by developing a comprehensive industrial data platform.

## 3. Objectives

The primary objectives of the project are:

1. Estimate the data volume generated by industrial machines.
2. Compare AWS, Microsoft Azure, and Google Cloud Platform.
3. Design a scalable cloud-based architecture.
4. Implement a PostgreSQL database for industrial data.
5. Demonstrate edge-to-cloud communication using MQTT.
6. Apply machine learning for anomaly detection and predictive maintenance.
7. Develop a dashboard for monitoring machine performance.

## 5. System Architecture

The proposed system follows an edge-to-cloud architecture.

Industrial machines generate sensor readings, production information, and operational events. These data are collected and processed through edge gateways before being transmitted to cloud infrastructure.

The cloud platform provides scalable storage, database management, analytics, machine learning, and visualization.

### Main components

- **Industrial machines:** Generate sensor and production data.
- **Edge gateway:** Collects and processes machine data.
- **MQTT broker:** Facilitates communication between edge and cloud components.
- **Cloud infrastructure:** Provides storage and computing resources.
- **PostgreSQL database:** Stores structured industrial data.
- **Machine learning module:** Performs predictive analytics.
- **Streamlit dashboard:** Presents analytical results.

## 6. Data Processing and Management

The project uses multiple public datasets, including:

- Bosch CNC Machining dataset.
- University of Michigan SMART CNC Mill Tool Wear dataset.
- Microsoft Azure Predictive Maintenance dataset.
- AI4I 2020 Predictive Maintenance dataset.

These datasets provide information about machine vibration, temperature, tool wear, machine failures, and operational conditions.

The data processing pipeline involves:

1. Loading the source datasets.
2. Cleaning and transforming the data.
3. Extracting relevant features.
4. Combining data into structured formats.
5. Preparing data for database storage and machine learning.

## 7. Database Implementation

PostgreSQL is used to store and manage industrial data.

The database includes structured tables for machine information, plant details, production records, alarms, and machine telemetry.

SQL queries are used to perform analytical operations such as:

- Machine performance analysis.
- Production and rejection analysis.
- Machine downtime analysis.
- Overall Equipment Effectiveness (OEE).
- Mean Time Between Failures (MTBF).
- Mean Time To Repair (MTTR).

The database enables efficient retrieval and analysis of industrial information.

## 8. Edge-to-Cloud Communication

The project demonstrates edge-to-cloud communication using MQTT.

An edge gateway collects machine data and transmits it through an MQTT broker to a cloud-side subscriber.

The system also demonstrates buffering and recovery during communication interruptions, helping maintain data reliability.

## 9. Machine Learning and Predictive Analytics

Machine learning is used to analyze machine data and identify operational patterns.

The project includes:

- Anomaly detection using machine vibration data.
- Tool-wear prediction using CNC machine data.
- Machine failure prediction.
- Failure-mode classification.

These models can help identify abnormal machine conditions and support predictive maintenance decisions.

## 10. Dashboard and Visualization

A Streamlit dashboard is developed to present machine and factory-level insights.

The dashboard enables users to monitor:

- Machine health.
- Production performance.
- Machine failures.
- Maintenance-related information.
- Analytical results.

Interactive visualizations help users understand operational trends and make informed decisions.

## 11. Cloud Provider Comparison

The project evaluates AWS, Microsoft Azure, and Google Cloud Platform based on criteria such as:

- Scalability.
- Cost.
- Data processing capabilities.
- Industrial IoT services.
- Integration with machine learning.
- Reliability and availability.

A decision matrix is used to compare the providers and identify a suitable cloud architecture for the smart factory.

## 12. Results and Key Findings

The project demonstrates the feasibility of building an integrated industrial data platform.

Key findings include:

- Edge processing can reduce the amount of data transmitted to the cloud.
- Cloud infrastructure provides scalable storage and analytics capabilities.
- PostgreSQL supports structured industrial data management.
- MQTT enables communication between edge and cloud components.
- Machine learning can support anomaly detection and predictive maintenance.
- Dashboards provide useful operational insights.

The project recommends an edge-first architecture with Microsoft Azure as the preferred cloud provider based on its documented comparison.
