**Reading.** Azure's lead comes from connectivity, analytics and integration, not from one inflated score. It is lost only when cost dominates the decision. Even then the three clouds are within 0.11 points, and the Azure IoT Hub cost could be cut further (cost model note 4).

## C.4 Final recommendation: Microsoft Azure (Central India), with an edge-first design

The scenario, not just the 4.22, supports this:

1. **Brownfield OPC UA is the critical path, and Azure covers it best.**
   - IoT Operations' OPC UA connector gives asset discovery, certificate management and write-back [S33] for the Fanuc FASOPC and SINUMERIK OPC UA servers [S79][S80].
   - That turns 100 controllers into registered assets without per-machine custom code.
   - AWS SiteWise Edge is close, but alarm rules and dashboards would have to be rebuilt after the IoT Events and Monitor retirements.
   - GCP would put the whole shop-floor layer on a partner contract.
2. **The plants already run on Microsoft.**
   - Typical Indian Tier-1 suppliers use Entra ID, Microsoft 365 and Excel/Power BI.
   - Fabric's Real-Time Dashboards and Power BI reach plant managers, quality engineers and the OEE review meeting without new tools or new logins [S40].
3. **Data stays near the plants.**
   - Central India is in Pune, beside Chakan, with South India (Chennai, beside Oragadam) as its pair [S43]. IoT Hub keeps data in the geography [S45].
   - **Mitigations for the two residency caveats:**
     - The IoT Operations Arc control-plane region is outside India [S32]. Only resource metadata goes there, and telemetry sinks are configured to Central India.
     - Defender for IoT's cloud mode routes to East US [S55]. Use its air-gapped / locally managed sensor mode.
4. **Edge-first removes Azure's two weaknesses.**
   - **72 h offline limit:** the plant gateway runs its own durable store-and-forward outbox, demonstrated with 0 messages lost in the MQTT demo, sized for 7 days. A 7-day buffer for the 40 machines at Chakan is about 21 GB (860 B/s per machine), which fits on the gateway's 1 TB SSD.
   - **Cost:** batching per machine-second and edge features keep the bill at about **₹0.8 lakh/month** (about ₹0.14 lakh if IoT Hub can be bypassed, cost model note 4). That is about 1.6% of the indicative ₹5.8 crore/year benefit.
5. **Skills are the main risk, and it is manageable.**
   - IoT Operations needs a small Kubernetes footprint (K3s / AKS Edge Essentials) at each plant [S32].
   - Mitigation: start with one pilot line at Chakan (P1, 40 HMC/VMC machines), use a system integrator for the first cluster, and train two plant IT staff before rolling out to P2 and P3.

**When to choose differently.**
- **AWS:** if management makes monthly cloud cost the dominant criterion (≥ 35 % weight), or if the plants standardise on Siemens Industrial Edge, where SiteWise Edge can be hosted directly [S10].
- **GCP:** for a data-science-led programme with heavy SAP analytics, *and* if a Litmus Edge contract is acceptable.
